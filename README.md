# Organ-Donation-Managnment
Organ Donation Management System is a database-driven application that manages donor, recipient, hospital, and organ records. It streamlines organ donation processes, tracks organ availability, and improves coordination between stakeholders for efficient and transparent organ allocation.

## Features

🔹 **Donor Management**

* Register and manage donor information.
* Update donation preferences and medical status.
* Track donor registration and donation history.

🔹 **Recipient Management**

* Register patients requiring organ transplants.
* Maintain recipient medical details and organ requirements.
* Monitor transplant eligibility status.

🔹 **Authentication & Security**

* Secure login with hashed passwords.
* Role-based access control (Admin, Hospital, Donor, Recipient).
* Session management using Flask.

🔹 **Organ & Matching Management**

* Manage available organs and donation records.
* Automatic donor-recipient matching based on blood group and organ type.
* Real-time availability tracking.

🔹 **Hospital Management**

* Hospitals can register and update transplant records.
* Verify donor and recipient information.
* Monitor transplant procedures and outcomes.

🔹 **Analytics & Reporting**

* View donation and transplant statistics.
* Generate reports on donors, recipients, and organ availability.
* Data visualization for healthcare insights.

 🔹**Tech Stack**

* **Backend:** Flask (Python)
* **Database:** MySQL with Connection Pooling
* **Authentication:** Flask-Login
* **Frontend:** HTML, CSS, Bootstrap
* **Security:** Password Hashing, Session Handling
* **Data Visualization:** Matplotlib / Chart.js
